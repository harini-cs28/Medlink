# Saved Models Directory

This directory stores trained machine learning and statistical time-series model artifacts (e.g., `.pkl`, `.joblib`, or `.json` metadata).

- **Demand Forecasting**: Time-series models (ARIMA, Prophet, LightGBM / XGBoost Regressor, Linear Baselines).
- **Shortage Prediction**: Classification models (Random Forest, XGBoost, LightGBM, Logistic Regression).
- **Explainability**: SHAP explainer objects and feature importance dictionaries.

Artifacts are generated by scripts in `src/models/` and notebooks `07_demand_analysis_and_forecasting.ipynb` & `08_shortage_prediction.ipynb`.
